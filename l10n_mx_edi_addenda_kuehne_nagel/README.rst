This module adds the KNRECEPCION addenda for Kuehne+Nagel and allows you to
generate electronic invoices (CFDI 4.0) with the required reception block.

**Table of contents**

.. contents::
   :local:

Configuration
=============

#. Go to Accounting > Customers > Customers
#. Open the Kuehne+Nagel partner
#. In the Sales & Purchase tab, Fiscal Information section, select
   **Addenda Kuehne Nagel**

Usage
=====

#. Go to Accounting > Customers > Invoices
#. Create an invoice for the partner configured above
#. Set the Customer Reference for the Purchase Order (optional; empty or
   ``PO`` + 4 uppercase letters + 9 digits)
#. Open the **Kuehne+Nagel Addenda** tab and fill:

   * File / Tracking Type
   * File / Tracking Number
   * Branch Centre
   * Transport Ref

#. Validate and stamp the invoice as usual
