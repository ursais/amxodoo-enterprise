Configuration
=============

To configure this module, you need to:

1. Go to Accounting > Customers > Customers
2. Create a new partner "Mabe" with the complete address
3. Add the "Mabe Plant Code" with the correct code
4. In the "Sales and Purchase" tab, in the Fiscal Information section
   select the "Addenda Mabe" for the addenda
5. In the same tab, fill the reference field for the AMS Code

Usage
=====

To use this module, you need to:

1. Go to Accounting > Customers > Invoices
2. Create a new invoice for Mabe
3. In the "Other Information" tab, add the customer reference
4. In the "Mabe Addenda" tab, add the reference 1, 2 and the amount with
   letter
