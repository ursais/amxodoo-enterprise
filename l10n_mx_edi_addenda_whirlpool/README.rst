This module adds the addenda of Whirlpool and allows you to generate
electronic invoices.

It emits a ``detallista`` addenda block using the invoice customer
reference as the order identification.

.. contents::
   :local:

Configuration
=============

To configure this module, you need to:

1. Go to Accounting > Customers > Customers
2. Create or open the Whirlpool partner with the complete address
3. In the Sales & Purchase tab, Fiscal Information section, select
   **Addenda Whirlpool**

Usage
=====

To use this module, you need to:

1. Go to Accounting > Customers > Invoices
2. Create an invoice for the Whirlpool partner
3. Set the Customer Reference (used as order identification in the
   addenda)
4. Validate and stamp the invoice as usual
