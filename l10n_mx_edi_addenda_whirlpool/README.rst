This module registers the Whirlpool (detallista) CFDI addenda for
Mexican electronic invoicing on Odoo Enterprise.

Assign **Addenda Whirlpool** on the customer
(``l10n_mx_edi_addenda_ids``) so the detallista order reference is
appended when the CFDI is generated.

.. contents::
   :local:

Configuration
=============

1. Go to **Accounting > Customers > Customers**.
2. Open the Whirlpool partner.
3. In the Mexican EDI / addendas section, add **Addenda Whirlpool**.

Usage
=====

1. Create a customer invoice for a partner that has **Addenda
   Whirlpool**.
2. Set the customer reference (``ref``) — it is exported as the
   detallista order id.
3. Confirm and stamp the invoice; the Whirlpool addenda is appended to
   the CFDI.
