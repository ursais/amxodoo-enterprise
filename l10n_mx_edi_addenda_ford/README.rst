Configuration
=============

To configure this module, you need to:

1. Go to Accounting > Customers > Customers
2. Create a new partner "Ford" with the complete address
3. In the "Sales and Purchase" tab, in the Fiscal Information section
   select the "Addenda Ford" for the addenda

Usage
=====

To use this module, you need to:

1. Go to Accounting > Customers > Invoices
2. Create a new invoice for Ford
3. In the "Other Information" tab, add the customer reference
4. In the "Ford Addenda" tab, add the sale reference
