Configuration
=============

Customer
--------

1. Go to Accounting > Customers > Customers
2. Create a new partner "Volkswagen" with the complete address
3. In the "Sales and Purchase" tab, select the "Addenda Volkswagen" for
   the addenda

Product
-------

1. Go to Sales > Products > Products
2. Create a new product or edit an existing one
3. In the "Accounting" tab, fill in the VW reference that corresponds to
   the part number

Usage
=====

To use this module, you need to:

1. Go to Accounting > Customers > Invoices
2. Create a new invoice for Volkswagen
3. In the "Other Information" tab, fill in the Customer reference field
4. In the "Addenda Volkswagen" tab, fill in the division, applicant
   name, applicant email and file fields
