## Customer

1. Go to Accounting > Customers > Customers
2. Create a new partner "Audi" with the complete address
3. In the "Sales and Purchase" tab, select the "Addenda Audi" for the addenda

## Product

1. Go to Sales > Products > Products
2. Create a new product or edit an existing one
3. In the "Accounting" tab, fill in the Audi reference that corresponds to
   the part number
